# 와글와글 퀴즈놀이터

> 다 같이 와글와글, 정답은 짜잔!

TV·프로젝터에 띄워 놓고 선생님(강사)이 진행하는 단체 퀴즈 웹앱입니다.
초등학생 · 중·고등학생 · 대학생·성인 수강생 · 직장인 연수, 네 대상별로 퀴즈 종류·문제·말투가 달라집니다.

## 기능
- 대상 4개 × 퀴즈 5종, 기본 문제 440개 (문제마다 정답·해설·난이도)
- 🎭 진진가(진짜·진짜·가짜): 세 문장 중 가짜 하나 찾기. 대상마다 22문제, 문장 순서는 매번 섞임. 문장을 누르거나 1·2·3 키로 반 전체 선택을 표시 → 정답 공개 때 가짜 도장·진짜 표시·이유 해설, 모둠별 +1 버튼
- 설정: 난이도(쉬움/보통/도전/전체), 문제 수(5/10/15/20), 힌트 타이머(10/15/20/30초/끄기/직접 입력). 시간이 지나면 힌트만 열리고 틀림 처리는 없음
- 진행: 진행률, 힌트 보기, 정답 확인(정답+해설), 다음 문제, 결과 화면
- 모둠 점수판(2~6모둠, +1/−1, 이름 바꾸기)
- 우리 반 문제: 추가/고치기/지우기, 엑셀·CSV·`|` 붙여넣기 가져오기, JSON 내보내기/가져오기 (브라우저 localStorage에 저장)
  - 진진가 붙여넣기: `진진가 | 문장1 | 문장2 | 문장3 | 가짜 번호(1~3) | 해설 | 난이도 | 주제 | 힌트`
  - JSON version 2: 진진가는 `{"kind":"jjg","q":"주제","stmts":[...3개],"fake":0~2,...}`. 예전 version 1 파일도 그대로 가져와짐
- 테스트: `npm test` (진진가 가져오기 호환·섞기·문제 수)
- 기본 문제 정답 미리보기(수업 전 확인용)
- WebAudio로 만든 효과음, 전체화면, 단축키(Space/Enter 정답·다음, → 다음, H 힌트)
- 배경음악: 퀴즈가 시작되면 자동 재생, 결과·홈 화면으로 나가면 멈춤 (상단 `배경음` 버튼으로 끄기, 설정은 브라우저에 기억). 힌트 직전 5초는 초침이 빨라짐(합성 BGM)

## 배경음악 바꾸기
- 기본: 앱이 직접 만드는 긴장감 있는 합성 BGM (A단조 112BPM, 심장 박동·초침·반음 베이스). 저작권 걱정 없음.
- 원하는 무료 음원을 쓰려면 `public/audio/quiz-bgm.mp3` 로 저장하세요. 파일이 있으면 그 곡을 반복 재생하고, 없으면 합성 BGM으로 돌아갑니다.
- 음원 라이선스가 CC BY(출처 표기 필요)라면 앱 하단(`App.tsx` footer) 등에 "Music: 곡명 — 작곡가 (사이트), CC BY 4.0" 을 꼭 적어 주세요. 볼륨은 `src/lib/sound.ts` 의 `BGM_VOLUME`.
